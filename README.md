# updates

Public downloads and update feeds for Kirill Prudnikov's Mac apps (Dictum, Cliplark, Textum, Shotlark, Note Calc).
No source code here — only release builds and [Sparkle](https://sparkle-project.org) update feeds.

- Feeds: `https://kvp5359-lab.github.io/updates/<app>/appcast.xml` (served by GitHub Pages from this repository).
- Builds: the **Releases** of this repository, tagged `<app>-<version>` (e.g. `dictum-0.2.0`).

Every update is signed with the apps' EdDSA key (checked by Sparkle) and, from the first public release on, with
Apple's Developer ID and notarized.
